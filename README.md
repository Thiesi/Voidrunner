# Voidrunner

A single-player space trading and exploration door game for BBSes. It is a single
Python file with no dependencies beyond the standard library.

Voidrunner ships bundled with [NetBBS](https://github.com/Thiesi/NetBBS) and is moving
here so it can also run under other BBS software (Synchronet, Mystic, ENiGMA½, …).
The plan is in [NetBBS#1214](https://github.com/Thiesi/NetBBS/issues/1214), and the work
is tracked in this repository's issues.

The banner is drawn from the game's own launch splash: its planet shader, wordmark
font and palette, rendered as pixel art by `art/render_banner.py`.
